# среда — социальный спецпроект о травле

Ранний технический прототип интерактивной веб-новеллы для подростков 12–18 лет, созданный по авторским экранам и user flow Figma.

**Статус:** 18 готовых экранов Figma перенесены в HTML в трёх адаптивных состояниях (60 композиций с мобильными подэкранами). Оригинальные отдельные изображения хранятся локально. Движок проходит 12 маршрутов к двум финалам; авторские заглушки сохранены по просьбе автора. Полное визуальное соответствие всех адаптивов пока не подтверждено — результаты и ограничения описаны в FIGMA-AUDIT.md.

## Запуск и требования

Стек: HTML, CSS, JavaScript (без React). Запуск живого просмотра: `node preview.cjs`, адрес http://127.0.0.1:8000/. Страница автоматически обновляется при изменении файлов. Для опубликованной версии сборка не нужна. Пересборка HTML из сохранённых контекстов: `npm install`, затем `npm run build:screens`. TypeScript используется только инструментом сборки; React в браузере отсутствует.

Резиновая вёрстка от 320 px, с использованием Flexbox, Grid и `clamp()`. Контрольные ширины: 320, 375, 768, 1084, 1440, 1920 px; после переработки constraints выполнены 216 браузерных проверок на 12 размерах окна, включая обязательные шесть ширин. Предусмотрена поддержка `prefers-reduced-motion`.

Оригинальные SVG/PNG экспортированы из Figma в `assets/figma/`; одинаковые файлы объединены по SHA-256 без изменения содержимого. Снимки целых экранов используются только для сравнения в локальной папке qa, интерфейс состоит из HTML, текста и отдельных ассетов. Дополнительные промежуточные сцены без готовых макетов остаются заглушками.
