# среда — социальный спецпроект о травле

Ранний технический прототип интерактивной веб-новеллы для подростков 12–18 лет, созданный по авторским экранам и user flow Figma.

**Статус:** работают стартовый экран, черновой диалог, первый выбор и навигация. Полные 3 выбора, 12 маршрутов и 2 финала ещё не реализованы. Оригинальные иллюстрации не загружены, поэтому текущая цветовая подложка временная. Не считать этот этап визуально готовой вёрсткой.

## Исходники и публикация

- [Экраны Figma](https://www.figma.com/design/Dh9CU2f4N47sWnTVCKPgVH/среда?node-id=400-688)
- [User flow Figma](https://www.figma.com/design/Dh9CU2f4N47sWnTVCKPgVH/среда?node-id=392-684)
- [Сайт на GitHub Pages](https://sunann2608.github.io/sreda_specproject/) — обновляется после отправки изменений в main.

## Запуск и требования

Стек: HTML, CSS, JavaScript (без React). Откройте `index.html` или запустите `python -m http.server 8000` в папке проекта. Для живого просмотра в редакторе можно использовать Live Server.

Резиновая вёрстка от 320 px, с использованием Flexbox, Grid и `clamp()`. Контрольные ширины: 320, 375, 768, 1084, 1440, 1920 px; браузерные тесты пока не выполнены. Предусмотрена поддержка `prefers-reduced-motion`.

Оригинальные SVG/PNG персонажей, фонов и логотипа должны быть экспортированы из Figma и сохранены без редактирования в `assets/`. Нельзя заменять их похожими генерациями. Черновые ветки после первого выбора не являются окончательным сценарием. Контакты помощи проверим перед публикацией.
